# XMB Reimagined

My portfolio as one XrossMediaBar that scales from a TV-sized screen down to a phone, in landscape and portrait. Plain HTML, CSS and JS with a WebGL wave. No framework, no build step.

- **Edit content:** `content.js` (name, boot message, categories, items, themes)
- **Run locally:** `python -m http.server` then open http://localhost:8000
- **Controls:** arrow keys, scroll (over the top row = categories), swipe, Enter / Esc
